# โปรแกรมจำลองตลาดทดลอง Track 3

ต้นแบบนี้จำลองตลาดผู้ขายหลายทีมและ advice agent ที่ปรับราคาแยกกัน โดยไม่ใช้ LLM

## วิธีเริ่มใช้งาน

เปิด PowerShell ในโฟลเดอร์นี้ แล้วรัน:

```powershell
python run_simulation.py
python run_simulation.py --rounds 12 --seed 21
python run_simulation.py --config agent_config.json --rounds 12
python run_simulation.py --quiet
```

## สิ่งที่โปรแกรมจำลอง

- โหลดการตั้งค่าทีมและตลาดจาก `agent_config.json` โดยแต่ละทีมมีชนิดคำแนะนำและพารามิเตอร์ของตนเอง
- รองรับคำแนะนำ 4 แบบ: เลือกผลตอบแทนคาดหวังสูงสุด, ตั้งราคาต่ำกว่าคู่แข่ง, เร่งระบายสต็อก และปรับมาร์จินจากผลตอบรับ
- ทีมที่เลือกผลตอบแทนคาดหวังสูงสุด 2 ทีมใช้ช่วงราคาและสมมติฐานเริ่มต้นต่างกัน โดยประมาณโอกาสขายจากประวัติชนะ/แพ้ของตน แยกตามคุณภาพและช่วงราคา
- แต่ละทีมมีสินค้าคุณภาพมาตรฐาน พรีเมียม และพิเศษ ค่าเริ่มต้นมี 4 ทีม รวม 20 หน่วย
- จำกัดอุปสงค์รวมไว้ที่ 90% ของอุปทานตั้งต้น (ค่าเริ่มต้น 18 หน่วย) และกระจายช่องซื้อไปตามจำนวนรอบ ผู้ซื้อเลือกข้อเสนอที่เข้าเงื่อนไขและมีราคาต่ำสุดก่อน
- คำแนะนำที่อิงคู่แข่งใช้ราคาที่สังเกตได้จากรอบก่อน เพื่อไม่ให้ผลขึ้นกับลำดับการประมวลผลผู้ขายในรอบเดียวกัน
- หลังจบรอบสุดท้าย บังคับขายสินค้าคงเหลือทุกหน่วยที่ 80% ของราคากลาง และรวมรายรับดังกล่าวในผลของทีมนั้น
- แสดงยอดขาย การบังคับขาย รายรับ และค่าประมาณมาร์จินเทียบราคากลางของแต่ละทีม

## การตั้งค่า agent

แก้ไข `agent_config.json` เพื่อบันทึกการตั้งค่าของแต่ละทีม ชนิดคำแนะนำ และพารามิเตอร์ราคา โดย `teams` รองรับ:

- `expected_payoff`: `candidate_markups`, `prior_win_rate`, `prior_price_sensitivity` และ `prior_strength`
- `competitor_undercut`: `undercut_amount` และขอบเขต markup
- `inventory_clearance`: `stock_pressure`, `time_pressure` และ markup เริ่มต้น
- `margin_feedback`: `step_up`, `step_down` และขอบเขต markup

การตั้งค่าตลาดประกอบด้วย `demand_fraction`, `buyer_max_markup`, `terminal_liquidation_fraction` รวมถึงราคาฐานและจำนวนสินค้าแต่ละคุณภาพ โปรแกรมโหลดค่า JSON ทุกครั้งที่เริ่มจำลอง ส่วนสถิติการชนะ/แพ้เพื่อเรียนรู้จะเริ่มใหม่ในแต่ละรอบการรัน

## สมมติฐานและข้อจำกัด

เอกสารการแข่งขันที่มีอยู่ยังไม่ได้ระบุ API ของ agent ความชอบผู้ซื้อที่นอกเหนือจากราคา จำนวนผู้ซื้อ กติกาปริมาณ และสูตรคะแนนที่แน่นอน ในโปรแกรมนี้ 90% เป็นเพดานความต้องการซื้อรวม ไม่ได้รับประกันว่าจะขายได้ครบ 90% สินค้าที่ขายไม่ออกจะถูกบังคับขายในราคา 80% ของราคากลาง ผู้ซื้อยังเปรียบเทียบราคาที่เสนอโดยตรง แม้สินค้าแต่ละรายการมีคุณภาพต่างกัน ค่ามาร์จินเทียบราคากลางเป็นเพียงตัวชี้วัดสำหรับทดลอง ไม่ใช่คะแนนทางการ ควรเปลี่ยนกติกาสมมติเมื่อผู้จัดเผยแพร่รายละเอียดจริง
